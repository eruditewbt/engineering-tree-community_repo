# Deploy GitHub Pages (Docs Folder)

This repo includes a static site in `docs/` for GitHub Pages.

## 1) Enable Pages
1. Go to your repo settings on GitHub.
2. Open **Settings → Pages**.
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main` (or your default branch)
   - Folder: `/docs`
4. Save.

## 2) Site URL
For the repo `engineering-tree-community_repo`, your Pages URL will be:

`https://eruditewbt.github.io/engineering-tree-community_repo/`

## 3) Update Links (Optional)
If your default branch is not `main`, update the GitHub links inside:

- `docs/index.html`
